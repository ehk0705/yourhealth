Diabète secondaire (type 3c)

Un diabète causé par une autre maladie ou par un traitement. Ce n’est ni un type 1, ni un type 2 classique.

Cause : atteinte du pancréas ou hormones Souvent : insulinodépendant Risque : glycémies instables

Idée clé : le type 1 = auto-immun ; le type 2 = résistance ; le secondaire = pancréas endommagé.

Diabète de type 1

Auto-immun

Cause : destruction des cellules du pancréas par le système immunitaire.

Insuline : production presque nulle → insuline obligatoire.

Début : souvent rapide.

Diabète de type 2

Résistance à l’insuline

Cause : résistance à l’insuline + production insuffisante.

Insuline : pas toujours nécessaire au début.

Début : progressif.

Diabète secondaire (type 3c)

Pancréas atteint

Cause : chirurgie, pancréatite, cancer du pancréas, etc.

Insuline : souvent nécessaire rapidement.

Particularité : glycémies souvent plus difficiles à équilibrer.

Comparaison simple

Type Cause principale Insuline Début
Type 1 Auto-immun : destruction des cellules Obligatoire Rapide
Type 2 Résistance à l’insuline Pas toujours au début Progressif
Secondaire (3c) Atteinte du pancréas (ou hormones / médicaments) Souvent nécessaire tôt Variable

Exemple typique : après pancréatectomie

Après une ablation partielle ou totale du pancréas, le corps ne produit plus assez d’insuline. Le diabète qui en résulte est un diabète secondaire, souvent appelé diabète pancréatogène (type 3c).

Point important : ce diabète est fréquemment insulinodépendant.

Page éducative. Pour un suivi médical, seul un médecin (endocrinologue) peut adapter le traitement.
